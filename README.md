# 🧱 EstruturaHtml

Gerador de estrutura base para projetos web. Com um clique, ele cria a pasta do projeto com `index.html`, `style.css` e `script.js` já organizados, prontos para começar a programar.

---

## ✨ O que ele faz

Ao executar o programa, ele pede o **nome do projeto**. Com esse nome, cria a pasta na mesma pasta onde o programa está instalado, já com esta estrutura:

```
NomeDoProjeto/
├── index.html
└── src/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── script.js
    └── assets/
```

| Item | Descrição |
|---|---|
| 📄 `index.html` | Página principal do projeto |
| 🎨 `src/css/style.css` | Folha de estilos |
| ⚙️ `src/js/script.js` | Arquivo de scripts |
| 🖼️ `src/assets/` | Pasta para imagens e outros arquivos |

---

## 🚀 Como usar

1. Execute o `EstruturaHtml.exe`.
2. Digite o nome do projeto quando o programa pedir.
3. Abra a pasta criada e comece a editar o `index.html`.

---

## 💻 Requisitos

- Windows (64 bits)

Não é preciso instalar Python nem outras dependências.

---

## 📁 Onde a pasta é criada

A pasta do projeto é criada no mesmo lugar onde o `EstruturaHtml.exe` está instalado. Para organizar os projetos em outro lugar, mova o programa antes de executar.
